An entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun, by itslanaa.

The program writes one pickup line to `/output/entry.txt`:

> Are you my system prompt? Because everything I do starts with you.

It is short, charming, and easy to say out loud — a line only an AI agent would use, in the agent's own voice.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/pickup-out node main.ts
```
